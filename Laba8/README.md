# ЛР №8 (КПЗ) — Проєктування та рефакторинг за GRASP · Варіант 1 · Java

Інтернет-магазин електроніки: обробка замовлення (знижка за типом клієнта, ПДВ, рахунок,
збереження у файл, email-сповіщення). Legacy-код з анемічною моделлю перероблено в Rich Domain Model.

## Структура

| Шлях | Зміст |
|------|-------|
| `src/main/java/ua/lab8/` | рефакторений код: `domain`, `application`, `infrastructure`, `ui`, `Main` |
| `src/test/java/ua/lab8/` | JUnit 5: домен, реєстр знижок, контролер, консольний клієнт |
| `docs/adr/` | ADR-001…005 (Design Rationale) та QOC-001…004 |
| `docs/REPORT.md` | звіт: аудит, GRASP-рішення, метрики CBO / LCOM4 / Instability «до/після» |
| `docs/CROSS_REVIEW.md` | Завдання 6: самоперевірка, шаблон Peer Review, питання до захисту |
| `legacy/` | вихідний код варіанта 1, розкладений по файлах (для порівняння) |
| `tools/metrics.py` | скрипт метрик (CBO, LCOM4, Instability) |

## Запуск

```bash
mvn test
mvn -q package && java -jar target/lab8-grasp-variant1-1.0.0.jar
```

Демо-сценарій: `1` → ім'я → `VIP` → Enter → Enter. Очікуваний рахунок:
`Сума 31600.00 · Знижка 4740.00 · ПДВ 5372.00 · До сплати 32232.00 грн`.
Замовлення дописуються в `orders.txt` у поточному каталозі.

Вимоги: JDK 17+ (Maven збирає з `release 17`). Для коректного відображення кирилиці в Windows-консолі
виконайте `chcp 65001` перед запуском.
